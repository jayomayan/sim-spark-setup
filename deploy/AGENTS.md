- Native Auth uses a role-and-database scoped auth, public search path and pgcrypto in fieldops, so migration tracking stays private and PostgreSQL 12 UUID defaults work without public CREATE privileges.
- The interactive installer dispatches helper-only before app checks and uses a dedicated helper account/private verified runtime; enrollment uses hidden codes and refuses HTTPS redirects so existing app state and secrets stay isolated.
- Resume only the verified pre-REST checkpoint after completed Auth migration; preserve Auth settings and signing keys, back up first, rotate only the unsaved authenticator password, and refuse any later outputs or ambiguous state to avoid overwriting partial installations.- Clean restart (--restart-clean) requires a typed RESTART confirmation, moves leftovers to a timestamped /var/backups backup instead of deleting, drops only the fieldops database and installer-created roles, and keeps service accounts, other sites and other databases untouched.
- Okta is registered in Auth as OAuth2 mode (custom:app-oidc) with Okta's userinfo endpoint, because Okta's code-flow ID token omits email_verified and Auth's OIDC mode reads only the ID token; never fake the claim via attribute mapping.
